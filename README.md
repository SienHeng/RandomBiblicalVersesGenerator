This is a Python program that randomly generates a sentence (with a randomly determined length based on the original distribution) of biblical verse (where all the words used are randomly selected from the words collected from the authentic King James Version Bible).

This is project pays attribute to Terry A. Davis, an American programmer who created the TempleOS operating system on himself in the course of 10 years. Terry was known for his unique and genius approach to system programming and his deep religious beliefs, which he often expressed through his work. The random biblical verse generator is inspired by Terry's original random word generator in TempleOS, which is implemented in HolyC programming language, a programming language created by Terry himself for the purpose of building TempleOS.
