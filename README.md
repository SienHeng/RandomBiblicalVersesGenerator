This is a Python program that randomly generates a sentence (with a randomly determined length based on the original distribution) of biblical verse (where all the words used are randomly selected from the words collected from the authentic King James Version Bible).

This project pays tribute to Terry A. Davis, an American programmer who created the TempleOS operating system over 10 years by himself. Terry was known for his unique and genius approach to system programming and his deep religious beliefs, which he often expressed through his work. Terry's original random word generator in TempleOS, which was implemented in HolyC, a programming language Terry created for TempleOS, inspires this project.
